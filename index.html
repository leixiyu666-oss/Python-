学习路线图

第一阶段：入门基础（1-2周）

环境搭建 → 基础语法 → 数据类型 → 流程控制 → 函数 → 文件操作

第二阶段：进阶提升（2-3周）

函数进阶 → OOP → 模块包 → 异常 → 标准库 → 迭代器 → 装饰器

第三阶段：生态实战（3-4周）

第三方库 → 爬虫 → 自动化 → 数据分析 → Web开发 → 综合项目

  • 每天 1-2 小时，持续 2 个月可达就业水平
  • 光看不练 = 没学，每章代码必须亲手敲一遍
  • 多做项目积累经验（实战篇准备了 10+ 个项目）

第一个 Python 程序

安装 Python 后，在终端输入 python 进入交互模式，或新建一个 hello.py 文件写入以下代码：

# 我的第一个 Python 程序
print("Hello, Python!")    # 打印输出

# 变量与输入
name = input("请输入你的名字：")
print(f"你好，{name}！欢迎开始 Python 学习之旅！")

# 简单计算
a = 10
b = 20
print(f"{a} + {b} = {a + b}")

在终端执行：python hello.py，即可看到输出结果。

新手常见问题

Q：我完全零基础，能学会吗？

A：完全可以。Python 是公认最适合入门的编程语言，本教程从安装开始一步步讲解。

Q：需要什么配置的电脑？

A：任何能正常运行的电脑都可以（Windows / Mac / Linux 均可）。

Q：学完能达到什么水平？

A：认真学完入门 + 进阶 + 2-3 个项目，可达到初级 Python 开发水平。

Q：需要学英语吗？

A：认识 26 个英文字母即可，代码中的英文关键词常见且固定。

Q：学 Python 能做什么工作？

A：数据分析、Web 后端开发、自动化测试、爬虫工程师、AI/机器学习等。
