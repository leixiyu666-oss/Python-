常用代码片段

# 1. 获取当前日期时间
from datetime import datetime
now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

# 2. 遍历列表带索引
for i, item in enumerate(["a","b","c"]):
    print(i, item)

# 3. 列表去重保持顺序
items = [1, 2, 2, 3, 1, 4]
unique = list(dict.fromkeys(items))  # [1, 2, 3, 4]

# 4. 字典排序
d = {"a": 3, "b": 1, "c": 2}
sorted_d = dict(sorted(d.items(), key=lambda x: x[1]))
# {'b': 1, 'c': 2, 'a': 3}

# 5. 合并两个字典
a = {"x": 1, "y": 2}
b = {"y": 3, "z": 4}
merged = {**a, **b}  # {'x': 1, 'y': 3, 'z': 4}

# 6. 检查文件是否存在
import os
if os.path.exists("file.txt"):
    print("文件存在")

# 7. 生成随机密码
import random
import string
password = "".join(random.choices(string.ascii_letters + string.digits, k=8))

# 8. 统计元素出现次数
from collections import Counter
data = [1, 1, 2, 2, 2, 3]
count = Counter(data)  # Counter({2: 3, 1: 2, 3: 1})

排错技巧与调试方法

方法1：print 调试法（最基础）
# 在关键位置打印变量值
def divide(a, b):
    print(f"DEBUG: a={a}, b={b}")  # 查看输入
    result = a / b
    print(f"DEBUG: result={result}")
    return result
方法2：使用断言 assert
def set_age(age):
    assert 0 < age < 150, f"年龄不合法：{age}"
    print(f"年龄设置为{age}")
方法3：使用 logging 模块
import logging
logging.basicConfig(level=logging.DEBUG,
                    format="%(asctime)s - %(levelname)s - %(message)s")

def func(x):
    logging.debug(f"函数被调用，x={x}")
    result = x * 2
    logging.info(f"计算结果：{result}")
    return result
常见错误速查
  • IndentationError：缩进错误，检查空格/Tab
  • NameError：变量未定义，检查拼写
  • TypeError：类型不匹配，检查运算符两侧类型
  • SyntaxError：语法错误，检查括号、冒号
  • ModuleNotFoundError：模块未安装，执行 pip install
