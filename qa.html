问答 & 易错点汇总

整理 Python 学习中 90% 新手会踩的坑，附带详细解释与正确写法。

90% 新手都会踩的坑

坑1：缩进错误

错误写法：

if True:
print("缩进不对！")  # ❌ IndentationError

正确写法：

if True:
    print("缩进正确！")  # ✅ 4个空格

Python 用缩进表示代码块，统一使用 4 个空格，不要混用 Tab 和空格。

坑2：列表作为默认参数

错误写法：

def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2]  ❌ 不是期望的 [2]

原因：默认参数在函数定义时创建，多次调用共用同一个列表对象。

正确写法：

def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

浅拷贝 vs 深拷贝

import copy

original = [[1, 2, 3], [4, 5, 6]]

# 浅拷贝：只拷贝外层，内层引用共享
shallow = copy.copy(original)
shallow[0][0] = 99
print(original[0][0])   # 99 ❌ 原列表也被修改了

# 深拷贝：完全独立复制
deep = copy.deepcopy(original)
deep[0][0] = 888
print(original[0][0])   # 99 ✅ 原列表不受影响

变量作用域问题

# 局部变量 vs 全局变量
x = 10

def func():
    x = 20  # 这里创建了局部变量 x，不影响全局
    print(f"函数内部：{x}")  # 20

func()
print(f"函数外部：{x}")     # 10

# 想要修改全局变量
def func2():
    global x
    x = 30
    print(f"函数内部：{x}")  # 30

func2()
print(f"函数外部：{x}")     # 30

字符串编码问题

Python 3 默认使用 UTF-8 编码。读写文件时指定编码，否则可能出现乱码。

# 写文件时指定 UTF-8
with open("test.txt", "w", encoding="utf-8") as f:
    f.write("中文内容")

# 读文件时指定 UTF-8
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

可变对象陷阱

# 两个变量指向同一个列表
a = [1, 2, 3]
b = a
b.append(4)
print(a)  # [1, 2, 3, 4] ❌ a 也被修改了

# 要复制列表，使用切片或 copy()
a = [1, 2, 3]
c = a[:]       # 切片复制
# c = a.copy() # 或者用 copy()
c.append(4)
print(a)  # [1, 2, 3] ✅
print(c)  # [1, 2, 3, 4]

Python 2 已于 2020 年停止维护。主要区别：print 在 2 中是语句（print "hi"），在 3 中是函数（print("hi")）；3 中的除法 / 是浮点除法；3 默认 UTF-8 编码。请直接学 Python 3。

GIL（全局解释器锁）导致同一时刻只有一个线程执行 Python 字节码。对于 I/O 密集型任务（网络请求、文件读写），多线程仍然有效；对于 CPU 密集型任务，使用 multiprocessing 多进程。

== 比较值是否相等；is 比较是否是同一个对象（内存地址）。
a = [1, 2]; b = [1, 2]; a == b # True; a is b # False
