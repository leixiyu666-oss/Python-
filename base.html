Python 零基础入门教程

本教程共 10 章，循序渐进，适合完全零基础的读者。每章配有代码示例，建议边学边练。

第1章 初识 Python

1.1 Python 是什么

Python 是一种解释型、面向对象的高级编程语言，由 Guido van Rossum 于 1991 年发布。它以简洁清晰的语法著称，被称为"可执行的伪代码"。

主要应用领域：

  • 数据分析：Pandas、NumPy、Matplotlib
  • 网络爬虫：Requests、Scrapy、BeautifulSoup
  • Web 后端：Django、Flask、FastAPI
  • 自动化运维：自动化脚本、办公自动化
  • 人工智能：TensorFlow、PyTorch、Scikit-learn
  • 游戏开发：Pygame
1.2 版本选择

Python 有 2.x 和 3.x 两大版本，3.x 是当前主流。请选择 Python 3.8 及以上版本（目前最新稳定版为 3.12）。Python 2 已于 2020 年停止维护，切勿学习。

1.3 环境安装（Windows）
  1. 打开官网 python.org/downloads
  2. 下载最新版 Python 安装包
  3. 安装时务必勾选 "Add Python to PATH"
  4. 打开终端（cmd），输入 python --version 验证
提示：Mac 用户推荐用 Homebrew 安装：brew install python3；Linux 用户使用包管理器：sudo apt install python3
1.4 编辑器选择与配置
  • IDLE：Python 自带的编辑器，适合第一周体验
  • VS Code：轻量免费，推荐！安装 Python 插件即可
  • PyCharm：专业 IDE，功能强大，适合做大项目
1.5 第一个程序：Hello World

新建文件 hello.py，写入：

print("Hello, World!")

在终端执行：

$ python hello.py
Hello, World!

两种运行方式：

  • 终端运行：python 文件名.py
  • 交互模式：终端输入 python 进入 >>> 提示符，直接输入代码
# 交互模式示例
>>> print("Hello")
Hello
>>> 1 + 2
3

2.2 缩进规则（Python 核心！）
易错点：Python 使用缩进来表示代码块，而不是 { }。同一代码块内的语句必须有相同的缩进（通常为 4 个空格）。混用空格和 Tab 会导致错误！ 
# 正确的缩进
if True:
    print("条件成立")    # 4个空格
    print("同一代码块")

# 错误的缩进（会报错 IndentationError）
# if True:
# print("没有缩进")   # ❌ 错误
2.3 变量

变量是用来存储数据的容器。Python 是动态类型语言，不需要声明变量类型。

name = "小明"       # 字符串
age = 18            # 整数
height = 1.75       # 浮点数
is_student = True   # 布尔值

print(name, age, height, is_student)
2.4 变量命名规范
  • 只能包含字母、数字、下划线
  • 不能以数字开头
  • 区分大小写（name ≠ Name）
  • 不能使用 Python 关键字
  • 建议使用有意义的英文单词，用下划线分隔（snake_case）
# 合法变量名
user_name = "Alice"
user_age = 25
temp_value = 36.5

# 不合法变量名（会报错）
# 123abc = "test"   # 数字开头 ❌
# user-name = "Bob"  # 包含连字符 ❌
# class = "python"   # 关键字 ❌
2.5 关键字（保留字）

Python 中有 35 个关键字，不能用作变量名：

False, None, True, and, as, assert, async, await, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield

第6章 字符串详解

6.1 字符串取值与切片
s = "Hello Python"

# 索引取值（从0开始）
print(s[0])     # H
print(s[6])     # P（第7个字符，索引6）
print(s[-1])    # n（倒数第一个）

# 切片 [start:end:step]
print(s[0:5])      # Hello（取索引0到4）
print(s[6:])       # Python（索引6到末尾）
print(s[:5])       # Hello（开头到索引4）
print(s[::2])      # HloPto（步长为2）
print(s[::-1])     # nohtyP olleH（反转字符串）
6.2 常用字符串方法
text = "  hello, python world!  "

# 去除空白
print(text.strip())       # "hello, python world!"
print(text.lstrip())      # 去掉左侧空白
print(text.rstrip())      # 去掉右侧空白

# 分割与拼接
print(text.split())       # ['hello,', 'python', 'world!']（默认按空格）
print("a,b,c".split(",")) # ['a', 'b', 'c']
print("-".join(["a","b","c"]))  # "a-b-c"

# 替换
print(text.replace("python", "Java"))  #  hello, Java world!

# 查找
print(text.find("python"))  # 8（返回索引位置，找不到返回-1）
print(text.index("python")) # 8（找不到会报错）

# 大小写转换
print("Hello".upper())      # HELLO
print("Hello".lower())      # hello
print("hello world".title()) # Hello World
6.3 转义字符
print("换行\n新行")          # \n 换行
print("制表符\t对齐")         # \t 制表符
print("单引号\'")             # 单引号'
print("双引号\"")             # 双引号"
print("反斜杠\\")             # 反斜杠\

# 原始字符串 r''（忽略转义）
print(r"换行\n不会生效")       # 原样输出：换行\n不会生效
# 常用于文件路径
path = r"C:\Users\name\Documents"

第7章 列表 & 元组

7.1 列表增删改查
fruits = ["苹果", "香蕉", "橘子"]

# 增
fruits.append("西瓜")        # 末尾追加 ["苹果","香蕉","橘子","西瓜"]
fruits.insert(1, "草莓")     # 指定位置插入 ["苹果","草莓","香蕉","橘子","西瓜"]

# 删
fruits.pop()                # 删除最后一个，返回"西瓜"
fruits.pop(1)               # 删除索引1的元素，返回"草莓"
fruits.remove("香蕉")        # 删除第一个匹配的元素
# del fruits[0]             # 删除索引0的元素

# 改
fruits[0] = "哈密瓜"         # 修改指定索引的元素

# 查
print(fruits[0])             # 访问指定索引
print(fruits.index("哈密瓜")) # 查找元素索引
print("苹果" in fruits)      # True/False
print(len(fruits))           # 列表长度
7.2 列表遍历与嵌套
# 遍历列表
for fruit in fruits:
    print(fruit)

# 带索引遍历
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# 列表嵌套（二维列表）
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[0][1])  # 2（第一行第二列）

# 列表推导式（快速生成列表）
squares = [x**2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
7.3 元组（不可变序列）

# point[0] = 5   # ❌ 报错！元组不可修改

# 元组的应用场景
# 1. 函数多返回值
def get_position():
    return (100, 200)

x, y = get_position()  # 元组解包

# 2. 保护数据不被修改
DEFAULT_CONFIG = ("127.0.0.1", 8080)

# 列表转元组、元组转列表
list1 = [1, 2, 3]
tuple1 = tuple(list1)    # (1, 2, 3)

第8章 字典 & 集合

8.1 字典增删改查
student = {"name": "小明", "age": 18, "score": 95}

# 查
print(student["name"])       # 小明（键不存在会报错）
print(student.get("name"))   # 小明（键不存在返回None）
print(student.get("gender", "未知"))  # 指定默认值

# 改
student["age"] = 19         # 修改
student["gender"] = "男"    # 新增键值对

# 删
del student["score"]        # 删除指定键
# student.pop("score")      # 删除并返回值

# 遍历
for key in student:                    # 遍历键
    print(key)
for value in student.values():         # 遍历值
    print(value)
for key, value in student.items():     # 遍历键值对
    print(f"{key}: {value}")
8.2 集合（去重 & 集合运算）
# 集合自动去重
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = set(numbers)
print(unique)  # {1, 2, 3, 4}

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)   # 交集 {3, 4}
print(a | b)   # 并集 {1, 2, 3, 4, 5, 6}
print(a - b)   # 差集 {1, 2}
print(a ^ b)   # 对称差 {1, 2, 5, 6}

类型可变有序可重复适用场景

元组 tuple否是是不可修改的数据，函数返回值
字典 dict是是（3.7+）键不可重复键值对应，JSON 数据

9.5 函数实战案例
# 案例1：简单计算器
def calculator(a, b, op):
    if op == "+":
        return a + b
    elif op == "-":
        return a - b
    elif op == "*":
        return a * b
    elif op == "/":
        return a / b if b != 0 else "除数不能为0"
    else:
        return "不支持的运算符"

print(calculator(10, 5, "+"))  # 15
print(calculator(10, 5, "*"))  # 50

# 案例2：判断素数
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

for num in range(1, 20):
    if is_prime(num):
        print(num, end=" ")  # 2 3 5 7 11 13 17 19

10.4 实战案例
# 案例1：记事本读写工具
def write_note(filename, content):
    with open(filename, "a", encoding="utf-8") as f:
        f.write(content + "\n")
    print("保存成功！")

def read_notes(filename):
    try:
        with open(filename, "r", encoding="utf-8") as f:
            return f.read()
    except FileNotFoundError:
        return "暂无笔记"

# 使用
write_note("notes.txt", "今天学习了文件操作")
write_note("notes.txt", "Python 真有趣")
print(read_notes("notes.txt"))

# 案例2：批量重命名文件
import os

def rename_files(prefix):
    files = os.listdir(".")  # 当前目录所有文件
    for i, f in enumerate(files):
        if f.endswith(".txt"):
            new_name = f"{prefix}_{i}.txt"
            os.rename(f, new_name)
            print(f"重命名: {f} -> {new_name}")
